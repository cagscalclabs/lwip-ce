lwIP-CE

TCP/IP networking for the TI-84 Plus CE

About

lwIP-CE brings the lwIP embedded TCP/IP stack to the TI-84 Plus CE graphing calculator. This page was served directly from a calculator over a USB-ethernet adapter.

Features

  • Full TCP/IP networking
  • TLS 1.3 with X25519 key exchange and AES-128-GCM
  • RSA certificate chain verification
  • DNS resolution, DHCP, NTP
  • HTTP client and HTTP server (this page)
  • JSON, XML, and URL parsers
  • Session ticket (PSK) resumption
