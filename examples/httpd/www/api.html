lwip_socket API

High-level connection API. Create a socket, register an event callback, call lwip_socket_connect(), then pump lwip_service_events() in a loop. Read data with lwip_socket_read().

TLS

Pass LWIP_SOCKET_ALTCP_TLS to lwip_socket_create(). TLS 1.3 is negotiated automatically. Certificate chain verification and session ticket resumption are built in.

Parsers

Cursor-based parsers for JSON, XML, and URL encoding are available in <lwip/parsers/json.h>, xml.h, and url.h. No heap allocation; no DOM tree.

Documentation
