### Simple IRC chat client

Uses lwIP-CE to connect to IRC.
Lets you edit server, channel, and nickname.
Settings saved on exit, reloaded on quit.

TCP => 6667
TLS => 6697

## Key Binds

[alpha] toggle aA0 mode
[del]   backspace
[clear] exit chat/exit app
[xtøn]  Shift (uppercase for one character)
[stat]  Toggle display of current stack memory usage
Else:
standard text input routine: [a-z][A-Z][0-9]
in A mode: [.] = :
in all modes: (neg) = ?
