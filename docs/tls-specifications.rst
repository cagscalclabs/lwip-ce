TLS Specification Compliance
=============================

Clause-by-clause mapping of the RFC, NIST SP, and FIPS requirements this
implementation targets to the code that satisfies or deviates from them.

Use the **Filter by grade** selector to narrow to a specific compliance status.
Every ``DEVIANT`` entry is expected to carry a ``<justification>`` explaining
why the deviation is intentionally retained.
