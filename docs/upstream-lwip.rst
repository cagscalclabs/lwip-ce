Upstream lwIP Documentation
===========================

lwIP-CE is a TI-84 Plus CE focused fork of lwIP. General lwIP behavior and APIs
are documented by the upstream project.

* `lwIP 2.1.x documentation <https://lwip.nongnu.org/2_1_x/>`_
* `Callback-style/raw API <https://lwip.nongnu.org/2_1_x/group__callbackstyle__api.html>`_
* `Original upstream README <https://github.com/cagscalclabs/lwip-ce/blob/tls/README-ORIG.md>`_

This site documents lwIP-CE-specific behavior and the curated public release API.
